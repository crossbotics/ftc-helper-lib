## Why

"Start from zero" installs Android Studio, gets the robot project and makes a first edit. Laptops
differ a lot (school-managed Windows, old Macs, Chromebooks). We need to know where it breaks.

## Setup

- A laptop that has never had Android Studio (a school laptop is the best test).
- Internet. About 10 GB free disk.

## Steps

1. Start a timer. Follow [Start from zero](../../docs/start-from-zero.md) from the top, exactly as written.
2. Write each step that did not match your screen (a button with another name, a missing menu).
3. Go on until its last section: a first build and an edit that builds.
4. Then run the simulator once (SIM-01 step 1 to 3).

## Pass rule

A first build passes within 75 minutes (not counting download time), and the simulator page opens.

## Record

- laptop, operating system and version, school-managed or not
- Android Studio version
- time (minutes), and download time if slow
- each step that did not match your screen
- any blocker (admin rights, firewall, disk space) and what fixed it

## If your robot is different

No robot needed. If your school blocks installs, say what was blocked: we can add a note for mentors.
