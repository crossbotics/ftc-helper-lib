# three.js

The 3D library the simulator page uses, bundled so the page works without the internet:
three.js r128 (`three.min.js`) and two files from the same release's `examples/js` folder
(`GLTFLoader.js`, `OrbitControls.js`). MIT licence: `LICENSE` in this folder covers all three.
https://github.com/mrdoob/three.js/tree/r128
