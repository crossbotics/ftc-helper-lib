# Add to your robot

Add one part at a time to the robot that drives. Each page adds one part to the five files.

**Why one at a time:** when only one part is new, a problem can only be in that part.

Every page has the same steps:

1. **What it is:** what the part does, and what it needs on the robot.
2. **Add it to the five files:** the lines for `Robot.java`, `Tunables.java`, `Controls.java`, and
   `Actions.java` and the autos when you need them.
3. **Find its numbers:** the finder that measures them.
4. **Check it, then tune it:** a short test on the robot, then the numbers to tune.
5. **Look it up:** the reference page with every setting.
