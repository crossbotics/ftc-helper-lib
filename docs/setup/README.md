# Set up: the tools and the library

**Set up gets the base system ready. It writes no robot code yet.** It installs Android Studio, gets
the robot project, adds the library, updates the hubs and makes the robot configuration. After it, you
**start using the library**: pick the code you start from, then work through the five robot files.

Do these pages in order, once. Each page is one job and ends with **Done when**. Already done a page?
Check its "Done when" and go on to the next.

| # | Page | Who |
| --- | --- | --- |
| 1 | [Before you start](01-before-you-start.md) | everyone |
| 2 | [Install Android Studio](02-android-studio.md) | each laptop |
| 3 | [GitHub and the robot project](03-github-and-the-project.md) | each laptop |
| 4 | [Add the library](04-add-the-library.md) | once per project (a mentor or code lead) |
| 5 | [Update the hubs](05-update-the-hubs.md) | once a season |
| 6 | [Build and install](06-build-and-install.md) | each laptop |
| 7 | [Make the robot configuration](07-robot-configuration.md) | once per robot |
| 8 | [Every practice: pull, change, commit, push](08-every-practice.md) | everyone |
| 9 | [The Terminal](09-the-terminal.md) | when a page gives you a command |
