# Set up 2: install Android Studio

**Set up, page 2 of 9.** Do it on each laptop.

**Android Studio** is the program you write and build the robot code in.

## Steps

1. Go to [developer.android.com/studio](https://developer.android.com/studio) and download Android Studio.
   **Which version:** FTC SDK 12.0 (the 2026-27 robot software) needs **Narwhal 3 Feature Drop or newer**.
   The newest version on that page is fine.
2. Install it with the normal settings.
3. Open Android Studio once.
4. Let it finish its first setup. It downloads the **Android SDK** (the tools that make Android apps).
   Accept the normal choices.
5. **Windows only:** install [Git for Windows](https://git-scm.com/download/win) with the normal settings.
   Then close Android Studio and open it again.
   **Why:** the setup pages use git in Android Studio. GitHub Desktop's git does not work there.

## Done when

Android Studio opens and shows its **Welcome** window.
