# Controls

The **controls** are what each gamepad button does in TeleOp. You write them in `Controls.java`, one line per
button. These pages show every way a button can work, what the drivers see and feel, and how to move the
library's own buttons.

| # | Page | You learn |
| --- | --- | --- |
| 1 | [How buttons work](01-how-buttons-work.md) | One gamepad or two. The four pieces of a button line. What a job can be, and modes. What INIT checks. |
| 2 | [Press types](02-press-types.md) | Every way to press: tap, hold, double tap, toggle, two buttons together, and more. One line of code each. |
| 3 | [What the drivers see and feel](03-see-and-feel.md) | Words on the button map, buzzes, lights, and values on the screen. |
| 4 | [Move the library's buttons](04-move-library-buttons.md) | Driving, pause, field-centric, the menus: put them on other buttons, or free them. |

**Start with page 1.** Each page has short examples. Copy the ones your robot needs.

**Next:** [How buttons work](01-how-buttons-work.md).
