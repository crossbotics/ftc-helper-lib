# Pick your start

**Before this:** [Set up](../setup/README.md) is done. The library is in your robot project.

Your robot's code is five files in `TeamCode`: `Robot.java`, `Tunables.java`, `Controls.java`,
`Actions.java` and an `autos` folder. You do not type them from nothing. You start from files that
are already written, and then change them. **Why:** code that already builds and drives is a safe
place to start. You change a few lines, not write a hundred.

Pick **one** start:

| Your robot | Your start | You get |
| --- | --- | --- |
| A **starter bot** from goBILDA (tank or Strafer), REV, AndyMark or Studica, built as the seller's guide says | [A starter bot](01-starter-bot.md) | The bot's whole code. Every part is in it, with the seller's names. |
| A robot **like one of our example robots**: for example mecanum + intake, tank + flywheel, a turret, odometry | [A common setup](02-common-setup.md) | That example's code. You delete what your robot does not have. |
| **Your own design** | [A blank slate](03-blank-slate.md) | The smallest code that drives. Then you add your parts one at a time. |

**A starter bot with your own changes** (a part added, taken off or moved)? Start from
[a starter bot](01-starter-bot.md). Then make your changes one at a time: the page says how.

**Not sure?** Pick the start that is most like your robot. You delete less and type less. You can
copy single lines from the other starts later.

All three starts end in the same place: **the five files in `TeamCode`, and the project builds.**
Then the [five files pages](../five-files/README.md) explain every line, and you make the robot drive.
