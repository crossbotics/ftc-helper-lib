| **Pose and path drawing: FTC Dashboard add-on + record-and-replay** (set aside 2026-10-21) | The mentor wants it, but has set it aside for now. | (1) An optional `dashboard` add-on (like `pedro/`). It shows the pose, the planned path, the trail and tuning graphs on Dashboard's field view. The robot sends them only in the PRACTICE profile. In COMPETITION it sends nothing, and INIT warns if Dashboard is still on ("run Enable/Disable Dashboard"). FTC Dashboard 0.6.0 (maven.brott.dev, 2026-05-16) has a saved on/off switch in the Robot Controller menu and an "Enable/Disable Dashboard" OpMode. It has no public method to switch it from code (`isEnabled()` only). It is built against SDK 10, so try a real SDK 12 build first. Rule R704.D bans such services at events: turn it off (or remove it), and ask the FIRST Q&A whether "off" is enough. (2) Record-and-replay: the robot writes the pose, the planned path and the step report to a file. Nothing streams, so events allow it. The simulator or the path builder replays the file. About 1-2 days for (1), 2-3 for (2). They share the drawing data. |
